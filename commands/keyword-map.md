# Keyword Map

## Goal

Give each important search intent one clear primary page and define which pages may support it.

## Evidence order

1. Current Search Console query/page data.
2. Existing website structure and canonical rules.
3. Real services, locations and commercial priorities.
4. Current search results and competitor evidence when needed.
5. Third-party keyword-volume data when available.

## Rules

- Cluster variants with the same intent instead of building one page per phrase.
- A primary owner is the page we want Google to treat as the best answer.
- Supporting pages may link to the owner but should not repeat its title, H1 and full commercial proposition.
- Booking, gallery, contact and utility pages should not accidentally become primary SEO landing pages.
- Do not invent a new page when an existing owner can be improved.
- Treat trailing-slash, legacy and typo URLs as technical/canonical issues, not separate keyword targets.
