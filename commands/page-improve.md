# Improve Existing Page

## Goal

Strengthen an existing page for a defined query cluster without creating additional overlap.

## Required inputs

- target URL
- primary query cluster
- Search Console performance
- competing URLs for the same query
- current page content/code
- business facts

## Pass 1 — ownership

Confirm the page is the correct owner. If not, stop and update the keyword map first.

## Pass 2 — search result clarity

Review:

- title tag;
- meta description;
- H1;
- canonical;
- indexability;
- structured data where relevant.

The page should make its single job obvious without keyword stuffing.

## Pass 3 — content usefulness

Check whether the page clearly answers:

- what the service/page is;
- where it is available;
- who it is for;
- options/pricing when appropriate and accurate;
- what happens next;
- proof/trust cues;
- FAQs that answer genuine buyer questions.

Use local details only when they are true and useful.

## Pass 4 — internal links

- Supporting pages should use descriptive anchors to link to the owner.
- Remove or soften internal anchors that make unrelated pages compete for the same head term.
- Keep conversion links obvious.

## Pass 5 — overlap

Compare sibling pages. If large sections could be moved between them without changing meaning, differentiate the user job or consolidate.

## Pass 6 — measurement

Record:

- edit date;
- target query/cluster;
- pre-change clicks/impressions/CTR/position;
- URLs changed;
- expected mechanism of improvement.

Do not judge a change from one or two days of ranking noise.
